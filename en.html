The Last Launcher

English overview — last updated October 14, 2026

The Last is an independent French Minecraft: Java Edition server with custom content built on NeoForge, currently in development. The Last Launcher is its desktop launcher (Windows first; macOS and Linux planned). It installs and updates everything needed to play on the server and starts the game straight into it.

How players sign in

  • Players sign in with their own Microsoft account in the system browser, on Microsoft's own sign-in page (OAuth 2.0 authorization code flow with PKCE, consumers tenant, scope XboxLive.signin offline_access, loopback redirect to http://localhost). The launcher never sees or stores the password and uses no client secret.
  • It then follows the documented chain: Xbox Live user token → XSTS token (rp://api.minecraftservices.com/) → login_with_xbox → game ownership check (/entitlements/mcstore) → Minecraft profile.
  • There is no offline or "cracked" mode. Accounts that do not own Minecraft: Java Edition cannot play. The launcher never bypasses authentication, license or safety checks.
  • Our game server runs with online-mode=true, so only genuine accounts can join.

What it downloads

  • Minecraft, its libraries, assets and Java runtime come only from Mojang's official servers, verified against Mojang's published hashes. No modified Minecraft jar is ever distributed.
  • NeoForge is installed from its official Maven repository; mods come from Modrinth or from our own file server.
  • Our pack manifest and news are digitally signed (Ed25519); every file is checked against the signed manifest before each launch. Launcher updates are signed as well.

Data and privacy

  • Only the refresh token issued by Microsoft is kept, encrypted on the player's computer (operating-system credential store). Minecraft access tokens stay in memory and are only passed to the game process. Tokens are never logged.
  • No telemetry, no analytics, no advertising, no hardware fingerprinting. The launcher sends no personal data to The Last, except when the player asks it to sign them in to our website: it then sends only public proof signed by Mojang (the player certificate and the signed profile), never a token.
  • Full privacy policy: thelastmc.fr/privacy.
